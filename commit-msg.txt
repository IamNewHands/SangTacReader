第六十轮：镜像竞速之前加一条 —— 页面自己的 origin 优先

- 根因修法：cookie（access/useri2）与 grantcontext 签发的章节 key 都属于设置它的那个
  host，而 bestDomain() 只按 /warp.php 延迟排序，于是正文与登录会被改写到别的镜像，
  带着一份不属于它的会话 —— 这就是 code 7 与「登录 success 但没登录」的共同解释。
- patchBestDomain 新增一条：页面 origin（location.origin）在站点镜像名单里、没被拉黑、
  这次探活没标 dead 时直接返回它，排在「手选线路」之后、「记忆镜像」与竞速之前。
  名单成员资格防篡改；页面 origin 回 code 7 仍会被拉黑并换镜像（不无限重试）。
- 测试新增 8 条断言（共 947 条）：更快的镜像不再赢、正文落在页面 origin、面板写出规则名、
  页面 origin 回 code 7 仍能换镜像、探活 dead 不钉、非站点 origin 不生效、手选线路仍优先。
- workflow 新增源码守卫：var page = pageOrigin(); 与 outranks the ping race。
